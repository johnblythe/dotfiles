# Jira Roadmap

All PDCR initiatives overview - portfolio view.

## Usage
```bash
/roadmap
```

## Quick Run
```bash
bash ~/code/management/scripts/jira-roadmap.sh
```

## What It Shows

### Overview
Count by status: Development, In Progress, To Do, Planning, Parking lot, Done

### Active Initiatives
All items in Development/In Progress/To Do with owner

### Planning Pipeline
Items in Needs Refinement or Ready for Dev

### Recently Completed
Done in last 30 days

## Output
- Full initiative list with status and owner
- Summary counts
