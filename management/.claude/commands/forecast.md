# Jira Forecast

Initiative ETA based on team velocity.

## Usage
```bash
/forecast PDCR-123
```

## Quick Run
```bash
bash ~/code/management/scripts/jira-forecast.sh PDCR-123
```

## Output
- Initiative summary and current status
- Work breakdown (done vs remaining pts)
- Team velocity (from trends data)
- Estimated sprints and completion date
- Confidence level based on % complete
