under the hood

What Claude actually does

Behind a simple interview, there's a full data pipeline pulling from three systems.

Resolve project from config
Reads jira-data/config.yaml, finds PDCR key, Confluence page ID, GitHub repo.
Query PDCR → Epics → Tickets
Follows 60 Implementation link type from PDCR to find all epics, then parent = EPIC-KEY for child tickets. Calculates completion %.
Detect active sprint
Hits board 389 for the current sprint name, start/end dates. Uses these to scope the report.
Auto-discover new tickets
Finds tickets created after sprint start date — these go in "New Tickets Created" section automatically.
Fetch PR details (from your answers)
Runs gh pr view for each PR number you give — gets title, URL, merge date.
Generate draft + publish via Confluence API
Formats everything into the status template, prepends to the Confluence page using ADF format.
🔗
Three systems, zero browser tabs. Jira (MCP), GitHub (CLI), Confluence (API) — all accessed from your terminal in one conversation.
