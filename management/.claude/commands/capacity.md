# Jira Capacity

Sprint planning helper - per-person load and rebalancing suggestions.

## Usage
```bash
/capacity
/capacity --team roio
```

## Quick Run
```bash
bash ~/code/management/scripts/jira-capacity.sh
```

## Output
- Per-person: items, points, status breakdown
- Team totals and averages
- Overloaded members (>150% avg)
- Unassigned work flagged
