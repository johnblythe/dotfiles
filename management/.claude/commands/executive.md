# Jira Executive

High-level stakeholder summary.

## Usage
```bash
/executive
/executive --team roio
```

## Quick Run
```bash
bash ~/code/management/scripts/jira-executive.sh
```

## Sections
- 📊 Initiative status (active count, recent completions)
- 🏃 Sprint health (progress %, status indicator)
- ⚠️ Top risks (large items, stale, blocked)
- 📈 Velocity trend (last 4 sprints)
- 🏆 Recent wins (last 7 days)
