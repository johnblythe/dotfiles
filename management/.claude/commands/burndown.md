# Jira Burndown

Sprint progress with ASCII burndown chart.

## Usage
```bash
/burndown
/burndown --team roio
```

## Quick Run
```bash
bash ~/code/management/scripts/jira-burndown.sh
```

## Output
- Sprint dates and timeline
- Points: total, done, remaining
- ASCII progress bar
- Pace check: on track vs behind
- Required pts/day to finish
