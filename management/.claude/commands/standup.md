# Jira Standup

Daily summary for standups - what moved, what's stuck, who needs help.

## Usage
```bash
/standup
/standup --team roio
```

## Quick Run
```bash
bash ~/code/management/scripts/jira-standup.sh
```

## Sections
- ✅ Completed (last 24h)
- 🚀 Started (last 24h)  
- ⚠️ Stuck (In Progress, no update 2+ days)
- 🆘 Needs Assignment (unassigned in sprint)
